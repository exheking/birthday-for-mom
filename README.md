# 💖 給老婆的專屬時光小遊戲 (A + C + D 闖關版)

這是一個特別為老婆定制的 3 合 1 溫馨闖關網頁小遊戲，融合了：
1. **關卡 1 (D - 萌趣篇)**：接住寶寶的愛（操控小推車接愛心、奶瓶，避開便便💩）
2. **關卡 2 (A - 溫馨篇)**：時光記憶寶盒（翻牌配對寶寶與生活照片，每翻一對彈出心底話）
3. **關卡 3 (C - 圓滿篇)**：拼出我們的幸福（全家福照片 3x3 點擊互換拼圖）
4. **終極彩蛋**：通關慶祝煙火、客製化深情告白信、以及老婆可隨時點擊使用的【愛心兌換券】！

---

## 🚀 如何立即試玩？

直接用瀏覽器雙擊打開資料夾中的 **`index.html`** 即可立即在電腦或手機上遊玩！
（目前已內建好預設插畫、清脆悅耳的音效合成器與彩帶特效，不需要安裝任何軟體）。

---

## 📸 如何換成您的真實照片？

只需在 `images/` 資料夾放入您挑選的照片，並開啟 **`config.js`** 修改對應名稱即可：

### 1. 替換第二關（翻牌回憶）的 6 張照片：
* 將 6 張照片（寶寶照、夫妻合照、生活照）放入 `images/` 資料夾（如 `images/baby1.jpg`、`images/baby2.jpg` ...）。
* 打開 `config.js`，將 `stage2.cards` 中的 `image` 改為您的相片檔名，並客製化當時的日期與「悄悄話」！

### 2. 替換第三關（全家福拼圖）的照片：
* 挑一張您最喜歡的全家福照片放入 `images/`，例如命名為 `family.jpg`。
* 打開 `config.js`，將 `stage3.fullImage` 改為 `"images/family.jpg"`。

---

## 💌 如何修改情書與兌換券？

打開 **`config.js`**，裡面的文字都非常直觀，您可以自由修改：
* **`wifeName`**：老婆的稱呼（例如「親愛的巧巧」、「最美媽咪」）。
* **`letterParagraphs`**：寫給她的真心話、感謝信。
* **`coupons`**：客製化心意兌換券（如「一日放風券」、「隨便買單券」、「精油按摩券」）。

---

## 🎵 加入專屬背景音樂 (BGM)
如果您有你們交往、婚禮或老婆特別喜歡的歌曲：
* 將 MP3 檔案重新命名為 **`bgm.mp3`**，直接放在本專案的根目錄。
* 點擊右上角的「🎵」按鈕即可直接播放！

---

## 📱 如何讓老婆在手機上玩？

* **方法一（區域網路/電腦分享）**：在同一家裡 Wi-Fi 下，透過 VSCode Live Server 或簡易網頁分享給手機瀏覽。
* **方法二（推薦・永久保存）**：將這個資料夾上傳到免費靜態網頁空間（如 **GitHub Pages**、**Vercel** 或 **Netlify**），會產生一個專屬網址，您可以把網址轉成 **QR Code** 印在生日卡片或小禮物上，讓她一掃就打開驚喜！
